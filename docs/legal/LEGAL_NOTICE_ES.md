## 2. Objeto y Ámbito de Aplicación

El presente Aviso Legal regula el acceso y uso de la plataforma **EducaCenter** (en adelante, "la Plataforma"), que ofrece servicios de:

- Control horario y fichaje laboral
- Gestión de vacaciones
- Generación de informes laborales
- Gestión multi-empresa para gestorías

### 3.1. Aceptación

- Proporcionar información veraz y actualizada

### 3.3. Uso Permitido
La Plataforma está destinada exclusivamente al control horario laboral conforme al RDL 8/2019. Queda prohibido:

- Usar la Plataforma con fines ilícitos
- Manipular o falsificar registros de fichaje

- Realizar ingeniería inversa o modificar el código
- Sobrecargar el sistema con peticiones automatizadas
- Suplantar identidad de otros usuarios

### 4.3. Inspecciones
